# Свой сервер HomeMusic в домашней сети

Краткая инструкция для тех, кто хочет поднять HomeMusic у себя: сервер на домашнем ПК и Android-приложение
на телефонах **в той же Wi-Fi сети**. Доступ из интернета (через VPS или свой домен) здесь не описан.

## Ограничения

- **Личный проект, без поддержки.** Проверяется только на Windows 10 + Docker Desktop (WSL2). На Linux с Docker
  скорее всего тоже заработает (в `MUSIC_ROOT` — путь Linux), но это не проверялось.
- **Только домашняя сеть.** Вне дома телефон до сервера не достучится. ПК должен быть включён и не уходить в сон,
  пока кто-то слушает.
- **Только Android.** На iPhone и компьютере работает веб-версия Хаба в браузере (`http://<IP ПК>:8080`): главная,
  библиотека, плеер, поиск и загрузки. Установить её как приложение («Установить приложение» в Chrome) по `http` нельзя —
  браузер требует HTTPS, но как сайт она работает.
- **Приложение собрано под сервер автора.** APK из [Releases](https://github.com/justman-1/HomeMusic-public/releases)
  при первом запуске предлагает адреса автора: свои адреса нужно один раз ввести вручную (шаг 6 ниже).
  Исходников приложения в этом репозитории нет, пересобрать его со своими адресами не получится.
- **Регистрация по коду и вход через Google в приложении** при первом запуске не работают (приложение спрашивает о них
  Хаб автора). Аккаунты заводятся так: админ создаёт пользователя в Navidrome или выдаёт код приглашения, по которому
  человек регистрируется в **браузере** на `http://<IP ПК>:8080`, а в приложении входит логином и паролем.
- **Обновления приложения не приходят сами.** Новую версию скачивайте из Releases и ставьте поверх: настройки и
  скачанное сохраняются.
- **Скачивание музыки идёт со сторонних сайтов** (hitmoz, SoundCloud, YouTube). Они меняются и иногда блокируют
  запросы — тогда часть песен временно не находится или не скачивается. Источники настроены в первую очередь
  под русскоязычную музыку (`config.yaml`). За то, что и откуда вы скачиваете, отвечаете вы.
- **Что работает не без настройки:**
  - ИИ-ассистент (распознавание скриншотов) — нужен ключ любого OpenAI-совместимого API (OpenRouter платный)
    или локальная Ollama. Без ключа работают ссылки и текстовые списки.
  - «Микс дня» лучше с бесплатным ключом Last.fm; без него собирается из остальных источников.
  - Звуковые векторы для миксов и «Моей волны» (сервис `embedder`) — нужна видеокарта NVIDIA с ~5 ГБ свободной
    видеопамяти, ~4 ГБ RAM и ~10 ГБ на диске (образ и веса модели). Без него миксы и волна работают, но подбирают
    музыку без анализа звука.

## Что нужно

- ПК с Windows 10/11, [Docker Desktop](https://www.docker.com/products/docker-desktop/) (WSL2) и [Git](https://git-scm.com/).
- Место на диске под музыку (≈ 8–10 МБ на песню в mp3 320).
- Телефон на Android в той же Wi-Fi сети.

## Установка сервера

1. **Скачать проект** (PowerShell):
   ```powershell
   git clone https://github.com/justman-1/HomeMusic-public.git HomeMusic
   cd HomeMusic
   ```

2. **Создать папку музыки** с подпапками, например `D:\Music`:
   ```powershell
   mkdir D:\Music\library, D:\Music\staging, D:\Music\.trash, D:\Music\.backups
   ```
   Уже есть своя музыка — положите её в `library` (по папкам «Исполнитель\Альбом»).

3. **Настройки:**
   ```powershell
   copy .env.example .env
   copy config.example.yaml config.yaml
   ```
   Сгенерировать два случайных ключа (выполнить дважды, результаты — в `.env`):
   ```powershell
   $b = [byte[]]::new(32); [Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b); [Convert]::ToBase64String($b).Replace('+','-').Replace('/','_')
   ```
   В `.env` заполнить минимум:
   ```ini
   MUSIC_ROOT=D:\Music
   # without a VPS any value will do: the tunnel service is not started
   VPS_HOST=127.0.0.1
   # the PC's address in the home network (see below)
   PUBLIC_MUSIC_URL=http://192.168.1.10:4533
   PUBLIC_HUB_URL=http://192.168.1.10:8080
   ND_PASSWORDENCRYPTIONKEY=<первый ключ>
   HUB_SECRET_KEY=<второй ключ>
   TIMEZONE=Europe/Moscow        # ваш часовой пояс
   ```
   Адрес ПК в сети — `ipconfig` → «IPv4-адрес» (вида `192.168.x.x`). Закрепите его за ПК в настройках роутера
   (резервирование DHCP), иначе после перезагрузки роутера адрес сменится и телефоны потеряют сервер.
   По желанию: `LLM_API_KEY` (ассистент), `LASTFM_API_KEY` (миксы); в `config.yaml` в
   `musicbrainz_user_agent` замените `you@example.com` своей почтой (так просит MusicBrainz).

4. **Запуск** (первая сборка — несколько минут):
   ```powershell
   docker compose up -d --build navidrome youtube-pot hub
   ```
   Есть видеокарта NVIDIA — добавьте ещё `embedder`. Сервис `tunnel` не запускайте: он нужен только для VPS.
   Простая команда `docker compose up -d` без списка сервисов запустит и его — так не надо.

5. **Админ Navidrome.** Откройте `http://localhost:4533` и создайте первого пользователя — он станет админом
   (и админом Хаба). Впишите его логин и пароль в `.env` (`NAVIDROME_ADMIN_USER`, `NAVIDROME_ADMIN_PASSWORD`)
   и перезапустите Хаб:
   ```powershell
   docker compose up -d --force-recreate hub
   ```
   Проверка: `http://localhost:8080` открывает Хаб, вход — тем же логином и паролем.

   Если с телефона адреса не открываются, разрешите в брандмауэре Windows входящие подключения на порты
   4533 и 8080 для частной сети.

## Подключение приложения

6. **Телефон:**
   1. Скачать [HomeMusic.apk](https://github.com/justman-1/HomeMusic-public/releases/latest/download/HomeMusic.apk)
      и установить (разрешить установку из браузера).
   2. На экране входа стереть предложенный адрес сервера и ввести свой: `http://192.168.1.10:4533`
      (адрес ПК и порт Navidrome). Дальше — логин и пароль Navidrome.
   3. Настройки → блок **HomeMusic**:
      - «Адрес Хаба» → `http://192.168.1.10:8080`;
      - «Домашний адрес Хаба» → тот же адрес (или очистить поле).

   После этого работают вкладка «Хаб» (каталог, загрузки, ассистент, свои файлы), «Поделиться» → Хаб и библиотека.

## Пользователи

- **Админ** — в Хабе (в браузере: «Ещё» → «Пользователи») → «Пригласить»: код приглашения (по умолчанию на 7 дней, `INVITE_DAYS`).
  Человек открывает `http://<IP ПК>:8080` в браузере, регистрируется по коду и потом входит в приложение
  этим логином и паролем (шаг 6).
- Или пользователя создаёт админ прямо в Navidrome (`http://<IP ПК>:4533` → «Пользователи»).

## Обслуживание

- **Включить / выключить:** `docker compose stop` и `docker compose up -d navidrome youtube-pot hub`.
  Контейнеры сами поднимаются после перезагрузки ПК, если Docker Desktop стартует при входе в Windows.
- **Обновить сервер** (yt-dlp устаревает — примерно раз в неделю-две):
  ```powershell
  git pull
  docker compose up -d --build navidrome youtube-pot hub
  docker image prune -f
  ```
  `prune -f` убирает прежние версии образов, оставшиеся без имени после пересборки.
- **Бэкапы** баз Хаба и Navidrome кладутся каждый день в `MUSIC_ROOT\.backups`; удалённое из Хаба — 30 дней
  в `MUSIC_ROOT\.trash`. Сама музыка — в `MUSIC_ROOT\library`, её копию делайте сами.
- **Что-то не так:** `docker compose ps`, `docker logs --tail 50 homemusic_hub`, `curl http://localhost:8080/healthz`.
  Подробности по настройкам и сервисам — [README.md](README.md).
